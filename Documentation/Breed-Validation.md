# Breed Estimate — Real-Photo Coverage Validation

Generated by `backend/scripts/validate_breed_coverage.py`. This is a coverage sanity check on real public photographs, not an academic benchmark: the labels come from Wikimedia Commons category membership, and the sample is small.

## Method

- Up to **4** Commons category photos per breed, plus the catalogue's own reference image.
- Model: `D:\Software\Felineye\backend\models\cat_breed_vit.onnx` (`D:\Software\Felineye\backend\app\data\cat_breed_labels.json`).
- Current thresholds: confidence **0.90**, margin **0.10**.
- Assertion mirrors `policy.decide_breed`: generic coat classes and non-catalogue breeds abstain before any threshold is considered.
- Sampled file titles, authors, and licences are recorded in `backend/tests/fixtures/breed-validation/manifest.json`.

## Recommendation

The highest-coverage point that keeps precision near 90% is confidence **0.90** and margin **0.10**: 29 asserted (33.7% fire rate), 26 correct, 3 wrong (precision 89.7%).

## Limitations

- Commons category membership is a weak label: a category can contain kittens, mixes, or mislabelled photos.
- The catalogue reference image is curated and may be easier than a typical user photo.
- This measures the breed classifier only. The species stage must also accept the photo as a domestic cat before the breed panel appears; that path is covered by `backend/tests/test_real_provider.py`.
- Breed output remains visual similarity, never pedigree verification.
